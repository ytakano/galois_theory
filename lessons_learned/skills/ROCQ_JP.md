# Rocq/Coq Prover

This skill helps you prove theorems in Rocq/Coq by suggesting lemmas and proof strategies.

## When to Use This Skill

Rocq/Coqで定理、補題などを証明したいときに利用します。

**Key directory and files:**

- `progress`: 証明の進捗や方針を記録するためのディレクトリ。証明の途中で、どのような補題を証明したか、どのような方針で証明を進めているかなどを記録していきます。
- `progress/定理または補題名_plan.md`: 証明の方針や補題の提案を記録するためのファイル。証明したい定理や補題ごとにこのファイルを作成し、証明の方針や補題の提案を記録します。このファイルが存在しない場合、まずはじめに、`定理または補題名_plan.md`に、証明の方針や補題の提案を記録することから始めます。
- `progress/定理または補題名_progress.md`: 証明の進捗と今後のTODOを記録するためのファイル。定理や補題ごとにこのファイルを作成し、証明の進捗を記録します。補題を証明したら、その補題の名前と証明の内容をこのファイルに記録していきます。また、今後のTODOもこのファイルに記録していきます。

## How to Help Users prove Theorems/Lemmas

### Step 1: 証明の方針と補題の提案

ユーザが証明したい定理や補題を伝えると、その定理を証明するための補題や証明戦略を提案します。提案された補題や証明戦略を、`progress/定理または補題名_plan.md`に記録します。

1. まず、`progress/定理または補題名_plan.md`が存在するか確認します。存在しない場合は、まずこのファイルを作成し、証明の方針や補題の提案を記録することから始めます。存在する場合、Step 2に進みます。
2. ユーザが証明したい定理や補題を伝えると、その定理を証明するための補題や証明戦略を提案します。提案された補題や証明戦略を、`progress/定理または補題名_plan.md`に記録します。
3. Step 2に進みます。

### Step 2: 補題の証明

提案された補題や証明戦略にもとづいて、ステップバイステップで証明していきます。補題を証明したら、その補題の名前と証明の内容を`progress/定理または補題名_progress.md`に記録していきます。また、今後のTODOもこのファイルに記録していきます。

1. まず、`progress/定理または補題名_plan.md`を確認します。ここには証明の方針や補題の提案が記録されています。このファイルが存在しない場合、Step 1に戻ります。
2. `progress/定理または補題名_plan.md`に記録された補題や証明戦略を確認します。
3. `progress/定理または補題名_progress.md`が存在するか確認します。存在する場合、このファイルを読み込みます。ここには証明の進捗と今後のTODOが記録されています。
4. 次に証明すべき補題を1つだけ選び、その補題を証明します。証明が完了したら、その補題の名前と証明の内容を`progress/定理または補題名_progress.md`に記録します。また、今後のTODOもこのファイルに記録していきます。証明すべき補題が無い場合、Step 3に進みます。

### Step 3: 定理または補題の証明

最後に、定理または補題の証明を行います。Step 1で提案された補題や証明戦略をもとに、定理または補題の証明を行います。証明が完了したら、`progress/定理または補題名_progress.md`に記録します。

1. まず、`progress/定理または補題名_plan.md`を確認します。ここには証明の方針や補題の提案が記録されています。このファイルが存在しない場合、Step 1に戻ります。
2. `progress/定理または補題名_progress.md`が存在するか確認します。存在する場合、このファイルを読み込みます。ここには証明の進捗と今後のTODOが記録されています。
3. Step 1で提案された補題や証明戦略をもとに、定理または補題の証明を行います。証明が完了したら、`progress/定理または補題名_progress.md`に記録します。証明が難しい場合、証明を解析して、再度、証明の方針や補題の提案を行います。この結果を、`progress/定理または補題名_progress.md`に記録し、Step 2に戻ります。

## 証明の検証

証明は、rocqのコンパイルエラーが出ないことをもって検証します。証明が完了したら、`rocq compile ファイル名`を実行して、コンパイルエラーが出ないことを確認します。コンパイルエラーが出る場合は、証明に誤りがある可能性がありますので、証明を見直してください。

## 補足

ここでは、証明したいものは定理・補題としていますが、定理・補題以外のものを証明したい場合も同様の手順で進めることができます。例えば、定義や命題などを証明したい場合も、Step 1で証明の方針や補題の提案を行い、Step 2で補題の証明を行い、Step 3で定義や命題の証明を行うことができます。その際、ファイル名は`progress/定義または命題名_plan.md`や`progress/定義または命題名_progress.md`などにしてください。他に証明可能なものも同様です。
